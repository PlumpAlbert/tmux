# Конфигурация tmux для удалённого сервера

Разместите этот каталог по пути `~/.config/tmux` на сервере. Конфигурация
рассчитана на удалённые coding-сессии через Ghostty: `pi`, Neovim, shell-панели
и долгие команды сборки/тестов. Для поддержки всплывающих окон нужен tmux версии
3.2 или новее. Убедитесь, что команда `infocmp tmux-256color` выполняется
успешно на сервере и на других хостах, к которым вы подключаетесь по SSH из его
панелей.

Перезагрузите конфигурацию командой `tmux source-file ~/.config/tmux/tmux.conf`,
затем нажмите `Ctrl-a I` (заглавная I), чтобы установить указанные плагины
через TPM. Сам TPM уже должен находиться в `~/.config/tmux/plugins/tpm`.

Копирование в буфер обмена использует OSC 52 через SSH, поэтому клиентский
терминал должен поддерживать и разрешать запись в буфер обмена. Если вы
подключаетесь через другой tmux, внешний tmux также должен поддерживать
передачу данных в буфер обмена (`set-clipboard on`). В конфигурации удалённого
сервера используется `set-clipboard external`, чтобы собственные команды
копирования tmux могли записывать данные в буфер обмена. Отдельная утилита
для работы с буфером обмена на сервере не нужна. Если скопированный текст
не попадает в локальный буфер обмена, выполните `tmux info` из подключённого
клиента и проверьте возможность `Ms`, отвечающую за работу с буфером обмена.
Для tmux 3.3+ дополнительно включён `allow-passthrough`, чтобы вложенные TUI
приложения вроде Neovim могли пробрасывать OSC52 и другие escape-последовательности.
Для Ghostty явно включены truecolor/RGB terminal features. Также включены
`xterm-keys` и `extended-keys` для лучшей передачи модифицированных сочетаний
клавиш в Neovim и другие TUI.

## Сочетания клавиш

Префикс — `Ctrl-a`.

| После префикса | Действие |
| --- | --- |
| `d` | Отключиться от сессии, оставив программы работать |
| `q` | Показать номера панелей и выбрать панель |
| `x` | Закрыть текущую панель после подтверждения |
| `X` | Закрыть текущее окно после подтверждения |
| `Q` | Завершить сессию после подтверждения |
| `s` / `w` | Открыть дерево сессий / окон |
| `S` | Включить/выключить `synchronize-panes` для текущего окна |
| `r` / `R` | Переименовать окно / сессию |
| `Tab` | Переключиться на предыдущую сессию |
| Обратная кавычка | Переключиться на предыдущее окно |
| `H` / `J` / `K` / `L` | Изменить размер панели; в течение короткого интервала можно повторять без префикса |
| `z` | Развернуть панель на всё окно или вернуть прежний размер |
| `!` | Перенести панель в новое окно |
| `p` | Открыть временную оболочку во всплывающем окне; `exit` закрывает её |
| `Ctrl-g` | Очистить видимый вывод и scrollback текущей панели |
| `[` | Войти в режим копирования: перемещение, `v` для выделения, `y` или Enter для копирования |
| `Ctrl-h/j/k/l` | Передать сочетание клавиш приложению |
| `F5` | Перезагрузить конфигурацию |

Выделение мышью также копирует текст. После загрузки плагинов SSH-split
назначает обработчики для обратной косой черты, Enter и `c`, сохраняя
SSH-подключения при разделении панелей.

Resurrect/Continuum намеренно не подключены: для `pi`/Neovim-сессий безопаснее
явно создавать и оставлять живыми нужные tmux-сессии, чем автоматически
восстанавливать устаревшие agent-процессы.

Из оболочки вне tmux создайте именованную сессию проекта или подключитесь
к существующей:

```sh
tmux new-session -A -s market -c ~/dev/market
```

Лимит истории увеличен до 200 000 строк, чтобы не терять длинный вывод `pi`,
сборок и тестов. В правой части статуса показываются текущая команда, basename
текущего пути, пользователь/хост и время; battery/plugin-индикаторы убраны как
неполезные для удалённого сервера.

Цвета статусной строки не зашиты hex-значениями: используются `default` и
палитра терминала `colour0`–`colour15`, поэтому оформление следует текущей теме
Ghostty. Текущие окно/сессия подсвечиваются `colour4`, путь — `colour6`,
предупреждения — `colour3`; блок `user@host` выделяется `reverse` без
фиксированного фона.
